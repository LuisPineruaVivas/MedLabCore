🖨️ CSS Print (Recomendado para POS-58 USB)

No requiere Web USB ni Web Serial. Usa el driver de Windows que ya está instalado. La impresora POS-58 debe estar configurada en Windows (Impresoras y Escáneres) — ya la tienes.

✅ Pasos: 1. Clic en "Previsualizar" para ver cómo quedaría el recibo en pantalla.
2. Clic en "Imprimir Prueba" — aparece el diálogo de impresión.
3. En el diálogo, selecciona POS-58 como impresora.
4. Si el resultado es correcto, la integraremos en la app.
Si el papel sale demasiado alto o con espacio en blanco:
• Abre Impresoras y Escáneres → POS-58 → Propiedades → Preferencias
• Cambia el tamaño de papel a 58mm × (altura personalizada mínima) o busca "Roll Paper" / "Continuous"
• También asegúrate que no haya márgenes extra configurados en el driver.
